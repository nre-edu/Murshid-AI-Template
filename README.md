# مرشد (Murshid-AI-Template)

قالب مجاني لبناء مساعد ذكي يجيب من مصادرك أنت فقط، ويعرض المصدر بجوار كل إجابة، ويعتذر إذا لم يجد الإجابة في مصادرك.

لا تحتاج إلى برمجة: أضف ملفاتك، وانشر على Vercel، وضع مفتاح الذكاء.

## أنشئ موقعك في 5 خطوات

### 1. انسخ القالب
اضغط **Use this template** أعلى هذه الصفحة، ثم **Create a new repository**، واجعل المستودع **Public**.

> بديل: حمّل المشروع وارفعه إلى مستودع جديد. عند الرفع عبر المتصفح قد تُهمل الملفات التي تبدأ بنقطة، مثل `.gitignore`، والموقع يعمل بدونها، لكن المستودع يفقد حماية منع رفع الأسرار.

### 2. أضف مصادرك
في مجلد `Knowledge`:
1. احذف الملف التجريبي `01_اساسيات_الذكاء_الاصطناعي_دليل_تجريبي.md`.
2. ارفع ملفاتك بصيغة `.md` أو `.txt`.

ملفات PDF وWord لا تُقرأ مباشرة؛ حوّلها إلى نص أولًا. إذا تركتها في المجلد فستظهر أسماؤها في `/api/status`.

> **تنبيه:** كل ما في المستودع العام مرئي للجميع. لا تضع معلومات سرية أو بيانات شخصية.

### 3. أضف هويتك (اختياري)
| ما تريد تغييره | أين |
|---|---|
| الشعار | ضع صورتك في مجلد [`Logo`](Logo/README.md) |
| أسلوب المساعد وتعليماته | [`config/instructions.md`](config/instructions.md) |
| الاسم والنصوص والأسئلة المقترحة | [`config/branding.json`](config/branding.json) |

### 4. أنشئ مفتاح الذكاء
أنشئ مفتاحًا من [Google AI Studio](https://aistudio.google.com/apikey). لا تضعه في أي ملف داخل المستودع.

### 5. انشر على Vercel
1. من [Vercel](https://vercel.com/new) اختر **Import** ثم مستودعك.
2. في **Environment Variables** أضف:
   - الاسم: `GEMINI_API_KEY`
   - القيمة: مفتاحك
3. اضغط **Deploy**.

تم! افتح رابط موقعك وجرّب سؤالًا.

إذا أضفت المفتاح بعد النشر، فاستخدم **Redeploy** حتى يعمل.

## تحديث الموقع لاحقًا
عدّل ملفات `Knowledge` أو `Logo` أو `config` على GitHub. يعيد Vercel النشر تلقائيًا، ويُحدَّث الفهرس بلا أي أمر.

## تعليمات المساعد
هناك مستويان:
- **تعليماتك** في `config/instructions.md`: اللهجة، وطول الإجابة، وطريقة المخاطبة، وأي توجيه تريده. اكتبها بلغة عادية.
- **القواعد الثابتة** في الكود: الإجابة من المصادر فقط، والاستشهاد، ومنع الاختلاق. إذا تعارضت معها تعليماتك فالقواعد الثابتة هي التي تُطبَّق.

لا تضع التعليمات في `Knowledge`؛ فكل ما في هذا المجلد يُعامل كمصدر للإجابات.

## تجهيز ملفات المعرفة
- العناوين (`#` و`##` و`###`) تقسم الملف إلى مقاطع وتحسن دقة البحث.
- يمكنك إضافة ترويسة اختيارية أعلى الملف:

```yaml
---
title: "دليل الطالب"
version: "1.0"
release_date: "2026-09-01"
---
```

- المجلد `Knowledge/_examples/` والملفات التي تبدأ بـ `_` لا تُفهرس.
- يدعم البحث العربية والإنجليزية، ويجيب المساعد بلغة السؤال.

## قبل النشر للعامة
- **الخصوصية:** تتيح [شروط Gemini](https://ai.google.dev/gemini-api/terms) لـGoogle استخدام بيانات الطبقة المجانية لتحسين منتجاتها، وقد يراجعها بشر. لذلك لا تُرسل معلومات سرية، ونبّه زوار موقعك ألا يكتبوا بيانات شخصية في أسئلتهم.
- **الاستخدام التجاري:** [خطة Vercel Hobby](https://vercel.com/docs/plans/hobby) مخصصة للاستخدام الشخصي غير التجاري. راجع الشروط إذا كان الموقع لجهة أو مؤسسة.
- **الحصة:** الحد الداخلي للطلبات (`RATE_LIMIT_PER_MINUTE`) يعمل لكل نسخة من الخادم فقط، وليس حماية كاملة. إذا نفدت حصة Gemini فستظهر رسالة واضحة حتى تتجدد.

## المشكلات الشائعة
| العرض | الحل |
|---|---|
| «الإعداد غير مكتمل» | أضف `GEMINI_API_KEY` في Vercel ثم Redeploy |
| «قاعدة الأدلة فارغة» | تأكد من وجود ملفات `.md` أو `.txt` داخل `Knowledge` |
| لا يجد إجابة موجودة في ملفك | جرّب كلمات من نص الملف، وأضف عناوين واضحة للأقسام |
| «نفدت حصة استخدام» | انتظر أو راجع حدود مشروعك في AI Studio |
| خطأ في مفتاح Gemini | تأكد من نسخ المفتاح كاملًا بلا مسافات ثم Redeploy |

## للمطورين
التشغيل المحلي:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements-dev.txt
copy .env.example .env
python run.py
```

على Linux وmacOS استخدم `source .venv/bin/activate` و`cp .env.example .env`. ثم افتح http://127.0.0.1:8000

الاختبارات:

```bash
pytest -q
```

### المتغيرات
| المتغير | الوصف |
|---|---|
| `GEMINI_API_KEY` | مطلوب |
| `GEMINI_MODEL` | اختياري، الافتراضي `gemini-3.5-flash-lite` |
| `MAX_QUERY_CHARS` | اختياري، أقصى طول للسؤال |
| `RATE_LIMIT_PER_MINUTE` | اختياري، حد الطلبات في الدقيقة |
